# EVE Command Center v2.4.0

- Unified branding across menus, settings, translated help, windows, logs, source namespaces, and project files.
- Public portable Windows download and in-app updates from this repository.
- Dark teal and gold desktop moon alerts for low fuel and unset drills, with a test button in Moon Report.
- Individual PiP tray entries refresh when the menu opens.
- Swapped mouse-button dragging fixes and independent FPS counter positioning and size.
- Existing mining, pilot, fitting, wallet, and corporation moon reporting features retained.

Upgrade: close the app and replace its executable. Keep your settings JSON files. Older filenames migrate automatically.

Moon alerts are monitored while Moon Report is open, including minimized. Closing Moon Report stops monitoring.
