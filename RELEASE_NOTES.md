# EVE Command Center v2.4.2

## Update overview

- New dark teal update window matching Command Center, with installed and available version cards.
- Read the changelog directly in the app, with formatted headings and bullet points.
- Choose **Update & Restart** or **Skip & Launch**. Startup checks no longer install updates without your choice.
- See download progress, retry failures, or cancel a download by skipping or closing the window.
- Open the full release page on GitHub.

Existing mining, pilot, moon reporting and preview features are unchanged.
